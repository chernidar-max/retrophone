# Інструкція зі збірки та використання CRT TV Retro Wallpaper

Проєкт створено у каталозі:
`C:\Users\isili\.gemini\antigravity\scratch\crt_tv_wallpaper`

---

## 🚀 Як зібрати APK на комп'ютері:

### Варіант 1: Через Android Studio (Найпростіший)
1. Відкрийте **Android Studio**.
2. Оберіть **File -> Open...** та вкажіть папку `C:\Users\isili\.gemini\antigravity\scratch\crt_tv_wallpaper`.
3. Зачекайте 10–20 секунд синхронізації Gradle.
4. Підключіть смартфон або емулятор і натисніть **зелену кнопку Run (▶)** або оберіть у верхньому меню **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
5. Готовий файл `.apk` з'явиться у папці:
   `crt_tv_wallpaper/app/build/outputs/apk/debug/app-debug.apk`

## 📺 Що реалізовано:
1. **GLSL Шейдер кінескопа (`crt_fragment.glsl`):**
   - Ефект викривлення скляної колби кінескопа (*Barrel Distortion*).
   - Рядки розгортки (*Scanlines*) та люмінофорні субпікселі.
   - Аналоговий шум та випадкові смуги розсинхронізації сигналу (*VCR / Rolling bar*).
   - Хроматична аберація по краях (розділення RGB).
   - **Анімація вимкнення:** плавне стискання зображення спочатку у вузьку горизонтальну лінію, потім у надяскраву точку по центру з фосфорним загасанням.
2. **Android Сервіс (`CrtWallpaperService.kt`):**
   - Працює як системні живі шпалери Android.
   - Енергоефективність: рендеринг автоматично зупиняється на паузу при відкритті будь-яких інших додатків.
   - **Подвійний тап по робочому столу:** запускає ретро-анімацію вимкнення кінескопа.
3. **Екран керування (`MainActivity.kt`):**
   - Прев'ю телевізора в реальному часі.
   - Повзунки для регулювання інтенсивності перешкод та викривлення скла.
   - Кнопка встановлення шпалер в один дотик.
